# SamsungTV4Mac

Воспроизведение любого видео с Mac на телевизоре Samsung Smart TV (Tizen) по локальной сети — без приложений на телевизоре и без настройки медиасервера. Написано на SwiftUI для macOS 14+.

## Возможности

- **Автоматический поиск телевизоров** по SSDP/UPnP — работает и с включённым VPN — или добавление по IP-адресу
- **Drag & drop** видеофайла (или *Открыть в программе → SamsungTV4Mac* в Finder) и кнопка **Воспроизвести на ТВ**
- **Проверка совместимости** через ffprobe: сразу видно, сможет ли телевизор воспроизвести файл как есть
- **Конвертация при необходимости** — Xvid/DivX, DTS, AVI и другие форматы, на которые телевизор пишет «Выбранный файл в настоящее время не поддерживается», конвертируются аппаратным кодировщиком Apple Silicon, обычно в 50–100 раз быстрее реального времени. Все звуковые дорожки и текстовые субтитры сохраняются, совместимые потоки копируются без перекодирования
- **Пульт на Mac** — пауза, перемотка, ±30 с, стоп, громкость телевизора
- **Mac не засыпает**, пока идёт трансляция
- Интерфейс на русском и английском

## Как это работает

Телевизор работает как DLNA *Media Renderer*. SamsungTV4Mac поднимает небольшой HTTP-сервер (с поддержкой Range — работает перемотка) и через UPnP AVTransport передаёт телевизору ссылку на файл. Файлы, которые телевизор не умеет декодировать, сначала перепаковываются или перекодируются через [ffmpeg](https://ffmpeg.org) в совместимый MKV (H.264 + AC3) и кэшируются в `~/Library/Caches/SamsungTV4Mac`.

| Воспроизводится напрямую | Конвертируется автоматически |
|---|---|
| Видео: H.264, HEVC, VP9, MPEG-2 | MPEG-4 Part 2 (Xvid/DivX), 10-битный H.264 и др. → H.264 |
| Звук: AAC, AC3, E-AC3, MP3 | DTS, TrueHD, FLAC, Opus, … → AC3 |
| Контейнеры: MP4, MKV, WebM, TS | AVI, WMV, FLV, … → MKV |

Другие DLNA-устройства (LG, Sony, Kodi и т. д.), скорее всего, тоже будут работать, но тестировалось на Samsung.

## Установка

### Скачать

1. Скачайте последний `SamsungTV4Mac-x.y.z.dmg` из [Releases](https://github.com/prony5/SamsungTV4Mac/releases) и перетащите приложение в *Программы*.
2. Приложение не нотаризовано, поэтому при первом запуске macOS его заблокирует. Нажмите на приложение правой кнопкой → **Открыть** или выполните:
   ```bash
   xattr -dr com.apple.quarantine /Applications/SamsungTV4Mac.app
   ```
3. Установите ffmpeg: `brew install ffmpeg`
4. Разрешите доступ к **локальной сети**, когда macOS спросит (нужно для поиска телевизора и управления им).

### Сборка из исходников

Достаточно Command Line Tools (полный Xcode не обязателен):

```bash
git clone https://github.com/prony5/SamsungTV4Mac.git
cd SamsungTV4Mac
./build-dmg.sh            # → .build/release/SamsungTV4Mac.app и .dmg
./scripts/test.sh         # запуск тестов
```

`UNIVERSAL=1 ./build-dmg.sh` — универсальная сборка arm64 + x86_64 (нужен Xcode).

## Решение проблем

- **Телевизор не находится** — проверьте, что он включён и в той же сети Wi-Fi/LAN. Добавьте его вручную кнопкой **+** по IP из *Настройки → Общие → Сеть → Состояние сети*. Гостевые сети и «изоляция клиентов» на роутере блокируют поиск и трансляцию.
- **«Не удалось определить адрес этого Mac»** — Mac и телевизор в разных сетях.
- **Воспроизведение обрывается** — телевизор берёт видео с Mac, поэтому Mac должен оставаться включённым. Приложение запрещает засыпание при простое, но закрытая крышка на батарее всё равно усыпит Mac.
- **Доступ к локальной сети** — если вы его запретили, включите в *Системные настройки → Конфиденциальность и безопасность → Локальная сеть*.
